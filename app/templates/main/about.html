About the project

{{ config.PROJECT_NAME }}

{{ config.PROJECT_NAME }} began life as a small command-line ticket booking script for {{ config.THEATRE_NAME }}. It has been rebuilt from the ground up into a secure, production-ready web application — while preserving the original idea of letting customers sign up, choose a seat class, add snacks and book tickets.

What changed

  • SQL-injection-prone string queries replaced with the SQLAlchemy ORM.
  • Plaintext passwords replaced with salted PBKDF2 hashes.
  • Hardcoded credentials moved to environment variables.
  • A responsive, accessible interface with dark & light themes.
  • Automated tests, linting and CI on every commit.

Open source

This project is open source under the MIT license and available for educational, learning and community contributions. Contributions are welcome on GitHub.
